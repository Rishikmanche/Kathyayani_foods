# Kathyayani_foods

A single-page, mobile-first website for **Kathyayani Foods**, selling fresh, made-to-order South Indian batters.

## Features
- **Direct WhatsApp Ordering:** Zero backend or checkout friction. Orders open directly in WhatsApp with pre-filled, quantity-aware messages.
- **Visual Identity:** Warm parchment aesthetic (`#F7F0E1`), oxblood maroon (`#4A1616`), temple brass gold (`#C79A3E`), and moong green (`#7C8C4E`) with `Marcellus`, `Cinzel`, and `Work Sans` typography.
- **Product Detail View (PDP):** Mobile bottom sheet and desktop modal featuring 4-slide carousel (Packaged Tub → Fresh Batter in Bowl → Plated Food → Nutrition & Ingredients), tabs, and quantity stepper.
- **Static & Fast:** Pure semantic HTML5, modern CSS3, and vanilla JavaScript ready for instant Vercel deployment.
